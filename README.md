# 📰 TechNews Today

**TechNews Today** é um desafio estudantil onde consiste em uma página web para um portal de notícias de tecnologia, desenvolvida utilizando HTML5 e CSS3. O projeto tem como foco a estruturação semântica de layouts de notícias e estilização visual moderna.

---

## 📌 Sobre o Projeto

Este repositório contém uma aplicação estática desenvolvida como parte de um desafio prático (`10a_desafio`). O objetivo é apresentar artigos, manchetes e novidades do mundo da tecnologia em uma interface organizada e legível.

### 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do portal de notícias (cabeçalho, artigos, seções e rodapé).
* **CSS3:** Estilização visual, regras de layout e formatação tipográfica (`10a_desafio.css`).

---

```
Technews today/

```

---

## 🚀 Como Executar o Projeto

Como o projeto é composto por arquivos estáticos, não há necessidade de instalação de dependências ou servidores complexos.

1. Faça o clone ou download deste repositório na sua máquina.
2. Navegue até a pasta `Technews today`.
3. Abra o arquivo `desafio10a.html` diretamente em qualquer navegador web (Google Chrome, Firefox, Edge, etc.) **ou** utilize a extensão **Live Server** no VS Code para visualizar a página em tempo real.
